# Bundled libraries

The plugin bundles and relocates the following libraries into its own namespace:

| Library | Version | Upstream source | License |
| --- | --- | --- | --- |
| Sparrow YAML | 1.0.22 | https://github.com/Xiao-MoMi/sparrow-yaml | GPL-3.0 |
| Sparrow UI | beta.38 | https://github.com/Catnies/sparrow-ui | Apache-2.0 |
| SQLite JDBC | 3.53.4.0 | https://github.com/xerial/sqlite-jdbc | Apache-2.0; bundled native dependencies retain their notices |

The license texts are included under `META-INF/licenses/` in the plugin JAR. Sparrow UI's
embedded `sparrow-ui-proxy.jarinjar` is preserved; its runtime proxy installer uses the
relocated package name. Neither library is included in the API-only JAR.

SQLite JDBC remains in its original `org.sqlite` namespace because its native JNI bindings
require those names. It lives in this plugin's private classloader. The JAR retains
`META-INF/maven/org.xerial/sqlite-jdbc/LICENSE` and `LICENSE.zentus`, including native
component notices. SQLite database work is performed by a dedicated worker.

Dependencies are obtained from the upstream Maven releases and snapshots repositories,
respectively. Consumers do not need to install either library as a separate server plugin.

# UltimateAdvancementAPI

UltimateAdvancementAPI `2.8.1-pro.3` is a compile-only dependency, distributed in `libs/`
with its corresponding source archive, build scripts and LGPL-3.0-or-later license texts.
It must be installed as a separate server plugin and is not bundled into either Farmersdelight JAR.
See [libs/README.md](libs/README.md) for provenance, artifact hashes and compatibility.

# Fluid tank content-pack assets

Nine tank model/texture files are obtained directly from Farmer's Delight commit
`0b424c370dc48197a9231771d55f0dcc3a36844e` and distributed with its MIT license and
vectorwing's attribution. Sixteen liquid-level model definitions are generated by
this project's [generator](tools/generate-tank-liquid-models.py). See
[asset notices](src/main/resources/craftengine/farmersdelight_fluids/ASSET-NOTICE.txt) and
[the accompanying license](src/main/resources/craftengine/farmersdelight_fluids/LICENSE).
The [asset manifest](src/main/resources/craftengine/farmersdelight_fluids/ASSET-ORIGINS.json)
records each upstream URL, fixed version, license and SHA-256, and each generated file's
hash. The nine upstream assets are not claimed as original artwork.

# FluidCore

FluidCore is a separate optional runtime dependency; no FluidCore implementation or API
class is bundled in this plugin. Its own distributions identify GPL-3.0 implementation
modules and the Apache-2.0 API module with uniquely named license files.
The matching compile-only server JAR and complete corresponding source archive are
provided in `libs/`; install the server JAR separately to use fluid features.
See [the dependency guide](libs/README.md#fluidcore-dependency).
