# 1.2.3 整合审查

本次合入内置村民功能和流体放置修复，提取共用的服务刷新方法。配置与配方格式不变。

- 外部方块的流体载荷交还所属插件处理；是否为原生储罐按实际方块行为判断，支持组合行为和其他命名空间。
